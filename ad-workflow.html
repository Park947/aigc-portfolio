从商品图，
到可投放的 15 秒。

围绕清洁工具、茶饮、美妆护肤、男士香氛与日用产品，已经形成从卖点提炼、分镜、Prompt 到成片质检的固定工作流。每个环节都服务于产品识别与卖点表达，而不只是生成一段好看的画面。

THE SYSTEM

一条广告，从 Brief 到成片都有明确的下一步。

  1. 01

    定位卖点

    读取商品图、核心卖点与目标用户，确定一条片子只需要观众记住什么。

    输出：卖点优先级 / 开场钩子
  2. 02

    设计表达

    按品类选择场景、视觉风格和节奏。功能型产品强调使用动作，感性产品突出材质、光线与氛围。

    输出：视觉方向 / 15 秒分镜
  3. 03

    生成与筛选

    将分镜转为时间轴 Prompt，锁定产品外形、主动作和镜头重点；筛选可剪辑素材并记录失败原因。

    输出：Prompt / 素材池 / 生成约束
  4. 04

    成片与复盘

    在剪辑中完成卖点强化、文字与声音控制，并用产品不变形、信息可读、节奏有效三个标准复盘。

    输出：成片 / 优化清单 / 模板迭代

REUSABLE SKILLS

把经验写成可调用的 Skill，而不是每次从零开始。

广告视频工作流已经被整理成可复用的指令结构。每次输入商品图、卖点、受众与限制，就能快速获得对应品类的创意钩子、分镜、Prompt 与质检重点。

SKILL / 01广告视频工作流

输入

输出

  • 产品外观、材质和使用方式的生成约束

  • 有效提示词与失败案例回写到模板，持续优化
SKILL / 02Seedance 视频 Prompt

将广告分镜进一步转为可执行的视频指令，明确主体、动作、景别、光线、节奏和画面约束，减少生成中常见的产品变形、场景偏移与卖点失焦。

QUALITY GATE

成片前，先过三道检查。

  1. 产品

    外观、材质、比例和使用方式是否稳定。

  2. 卖点

    开场钩子、核心信息和产品露出是否清楚。

  3. 交付

    节奏、字幕、声音与不同平台比例是否可用。
