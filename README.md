## 已收录作品

网站已内置 10 个作品项目与对应海报、视频：两部短剧、三部叙事 / 视觉短片，以及五支品牌广告。点击项目卡片即可在弹窗中播放本地视频；《财神爷来我家送财，结果被我妈拉去相亲》支持切换第 1 至第 7 集。

媒体资源位于 `assets/posters/` 与 `assets/videos/`。其中《日蚀丛林》当前为带生成平台标记的展示版，替换为无水印导出时，直接覆盖 `assets/videos/worlds-between.mp4` 即可。
